# Warehouse Management System

This is a JavaScript/React warehouse management module built with Vite. The original design is available at https://www.figma.com/design/uwt4o8HBjzmzAUitcEt7zH/Warehouse-Management-Module.

## Running the code

Run `npm install` to install the dependencies.

Run `npm run dev` to start the development server.

Run `npm run build` to create a production build.
